# Birthday Surprise

## How to run
1. Extract this folder.
2. Open `index.html` in a browser.
3. Click the envelope, continue through the birthday message, write a wish, and submit.

## Files
- `index.html`: page structure and text
- `style.css`: colors, layout, envelope, cake, and responsive design
- `script.js`: buttons, page navigation, wish submission, and fireworks

The Google Fonts import needs an internet connection. The rest of the page works locally.
